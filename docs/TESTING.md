# تقرير التحقق

تاريخ الإعداد: 25 سبتمبر 2026.

- نجح build الإنتاجي بواسطة Vite 7.3.6 وReact 19.3.0.
- نجحت 13 مجموعة اختبارات تكامل باستخدام محرك PGlite المحلي وDrizzle، دون اتصال بخدمة خارجية.
- فُحصت الواجهة في المتصفح: دخول المدير، إنشاء برنامج وحفظه، شاشة الهاتف بعرض 390px، دخول الطالب وتسليم اختبار وظهور نتيجة 100%، وشهادة عامة مع QR.
- الاختبارات تشمل:
  1. المهاجرات القابلة للتكرار ومنع seed من الكتابة على قاعدة مستخدمة.
  2. منع الدخول غير المصرح والتحقق من Origin.
  3. صلاحيات الطلاب والشؤون الأكاديمية والمالية.
  4. عزل بيانات الطالب وإخفاء الإجابات الصحيحة وحقول كلمة المرور.
  5. إنشاء برنامج ورفض الربط بدفعة من برنامج آخر.
  6. ملكية المحاضر والتحقق من تسجيل الطالب عند الحضور.
  7. منع تجاوز المستحق وتكرار مرجع الدفع.
  8. التصحيح الصحيح ومنع التسليم الناقص أو المكرر وتجميد الأسئلة المنشورة.
  9. شروط الشهادة والتحقق العام والإلغاء وملكية الوصول إلى QR.
  10. سجل التدقيق ومنع المدير من تعطيل نفسه.
  11. تحديد محاولات الدخول.
  12. إبطال الجلسات عند تغيير كلمة المرور.
  13. بقاء النتائج السابقة ظاهرة بعد إكمال التسجيل أو الانسحاب مع منع محاولة جديدة.

راجع README لإعادة الاختبارات: `pnpm test` ثم `pnpm build`.

لا يعني نجاح هذه الاختبارات تنفيذ اختبار حمل أو تدقيق أمني خارجي. لم يُختبر اتصال Neon حي أو TLS ونطاق نشر أو Docker فعليًا. هذه الخطوات تُنفَّذ على البيئة الجديدة عند الإعداد.
