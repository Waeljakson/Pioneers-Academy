# نطاق MVP وخطوات التوسعة

هذه النسخة تنفذ دورة أساسية كاملة ببيانات حقيقية في Postgres: إنشاء حساب → قبول → تسجيل → جدول وحضور → اختبار ونتيجة → فواتير ومدفوعات → إكمال وشهادة.

| المجال | المتاح | مؤجل |
|---|---|---|
| الهوية | شكل مستلهم من الصورة وأيقونة أكاديمية أصلية من Lucide | الشعار الرسمي كأصل منفصل |
| الطلاب | بيانات أساسية وقبول ورقم أكاديمي وتسجيلات | مستندات القبول والملف الموسع والتصدير الجماعي |
| البرامج | أنواع مرنة، تخصصات، دفعات، مقررات | متطلبات سابقة وخطط ساعات معتمدة |
| الحضور | سجل يدوي والتحقق من التسجيل وملكية المحاضر | QR حضور وتكامل الفيديو |
| الاختبارات | MCQ، 4 اختيارات، تصحيح آلي، محاولة واحدة | توقيت وإعادة محاولة وأسئلة مقالية وتوليد عشوائي ومراقبة |
| الإنجاز | اعتماد يدوي للصلاحية الأكاديمية | احتساب آلي بسياسات نجاح وحضور |
| المالية | أقساط ومدفوعات جزئية ومصروفات وإيصال | دفع إلكتروني وتسويات واسترداد وضرائب وتقارير مالية معتمدة |
| الشهادات | إصدار وإلغاء وQR وتحقيق عام وطباعة | توقيع رقمي وادعاءات اعتماد جامعي أو حكومي |
| الحسابات | دخول وتغيير كلمة مرور وإعادة تعيين إدارية | دعوات بريد وتحقق البريد وMFA واستعادة ذاتية |
| التشغيل | Node.js + Neon، مع Dockerfile اختياري | مراقبة ونسخ احتياطي وتنبيهات خاصة بالمنصة |

تُنشأ حسابات الطلبة والمحاضرين من وحداتهم، وحسابات المدير والشؤون الأكاديمية والمالية من «المستخدمون والصلاحيات». تعديل الدور مباشرة غير متاح كي لا يفسد ارتباط الحساب بملف الطالب أو المحاضر. يمكن تعطيل الحساب من لوحة المدير.

لا توجد خاصية حذف في هذه النسخة للمحافظة على الترابط والسجل الأكاديمي والمالي. البرامج يمكن تعطيل إتاحتها، والطالب يُرفض أو ينسحب تسجيله، والشهادة تُلغى. صفحات الإدارة تدعم إضافة السجلات وتعديل الحقول الآمنة المحددة في catalog، مع ثبات علاقاتها بعد الإنشاء.

لم يُشغّل seed أو migrations على Neon حقيقية في هذه الجلسة، ولم يُنشأ أو يُعدّل أي مستودع GitHub. لا توجد بيانات مدرسة أو endpoint مستعار في الحزمة.
